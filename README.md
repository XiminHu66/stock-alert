# Stock Alert

一个可直接部署到 GitHub Pages 的个人交易观察台：自选股、准实时行情、新闻、期权活跃度、技术指标、模型买卖观察区间和自定义价格提醒。

## 功能

- 默认股票列表继承 `deskboard`：SPX、QQQ、AAPL、SMH、NVDA、BTCUSD、INTC、UNH、HOOD、NOW、VST、MRVL。
- 自由添加/删除股票，自选列表与价格区间保存在浏览器 `localStorage`。
- 自动任务在美股常规交易时段每小时更新全列表报价、历史行情、相关新闻和期权快照。页面上的“手动刷新”会同时强制读取 Pages 与 GitHub 中较新的快照、尝试直连刷新当前股票价格，并立即重算模型。
- 技术模型使用 SMA 20/50/200、RSI 14、MACD、布林带、ATR 14、52 周高低点与近期支撑阻力，并在浏览器中做无前视的滚动历史检验。
- 默认自选股会抓取 4 个代表性期权到期日（最近、约 1 周、约 3 周、约 6 周），可在面板中切换；成交活跃度、Put/Call 比趋势、行权价 OI 分布、Put Wall、Call Wall 与 Max Pain 会随所选日期一起更新。这些是描述性统计，不是逐笔买卖方向。
- PE、预期 PE、市净率、PEG 与增长率作为独立估值背景显示，不混入技术买卖区间。
- 股票进入用户设定的买入或卖出区间时，高亮自选项并显示页面提醒；用户可自行启用浏览器系统通知。
- 响应式布局，支持桌面和手机、深色和浅色主题。

## 数据说明

完整数据由 GitHub Actions 中的 `yfinance` 获取，计划在纽约时间交易日 09:41–15:41 每小时运行一次；任务会在同一次运行中更新轻量报价、提交数据并重新部署 Pages，避免工作流递归触发限制与多个任务互相覆盖。轻量报价工作流仍可在 Actions 页面手动运行。网页会并行检查 Pages 同域文件与 GitHub 原始文件，并采用 `generatedAt` 较新的版本，以减少 CDN 陈旧缓存影响。页面打开后会尝试直连刷新当前股票；手动刷新始终会重试直连，即使浏览器或 Yahoo 先前曾限制跨域/频率。顶部会分别显示实际行情时间和数据路径，期权选择器会显示所选到期日快照年龄。GitHub 的计划任务属于 best-effort，仍可能因平台调度繁忙而延迟。静态网页的按钮无法安全地直接启动需要写权限的 GitHub Action，因此完整期权链仍以最近一次小时快照为准。模型在浏览器中计算，每次成功报价都会重新推演。期权数据是成交量、未平仓量和隐含波动率快照，不是逐笔成交方向或付费订单流。

“指标一致度”只表示模型内部技术信号的一致程度，不是上涨概率。滚动检验记录历史时点进入模型买入区后 20 个交易日的表现，不含交易成本、滑点、税费与分红，也不是独立样本的生产级回测。模型区间只用于研究和价格提醒，不构成投资建议。财报、宏观事件和跳空可能令历史技术位立即失效。

## GitHub Pages

仓库包含官方 Pages Actions 部署工作流。首次使用时，在仓库 **Settings → Pages → Build and deployment → Source** 选择 **GitHub Actions**，然后重新运行 `Deploy Stock Alert to Pages` 工作流。

## 本地预览

```bash
python -m http.server 8000
```

访问 `http://localhost:8000`。
